# 肌录 · UI 原型评审版（final-2）

肌录——面向中国用户的免费专业健身工具。本仓库是 **final-2 原型（13 页）的网页评审版**，部署于 GitHub Pages，供随时查看与反馈。

## 看什么

13 页 = 首页 / 动作库 / 动作详情 / 拉伸库 / 拉伸详情 / 执行页 / 计划列表 / 计划详情 / 历史日历 / 我的 / AI 问答 / 模板详情 / 总结页。底部导航可点，动作/拉伸卡片可进详情。

## 版权说明（PRD 7.4）

- 演示图占位块：本地评审版挂内部书图（《肌肉力量训练彩色图谱》《拉伸运动系统训练》）；**公开网页版按 PRD 7.4 热替换策略展示占位块**，书图不出内部环境
- 解剖肌肉图为 SVG 路径几何（MuscleMap，MIT 授权，已合法提取）
- 其余内容为事实性数据 + 自有文字
